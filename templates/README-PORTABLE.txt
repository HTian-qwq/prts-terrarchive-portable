PRTS Terrarchive Portable（社区非官方便携发行版）

1. 完整解压 ZIP，不要直接在压缩软件中运行。
2. 双击“Start PRTS.cmd”。启动窗口需要保持打开；关闭窗口会停止本地服务。
3. 浏览器或 Edge 应用窗口打开后，在设置中配置模型。
4. 设置 → 插件 → PRTS 语料，选择皮肤并从 ModelScope 下载资料。
5. 新建会话并选择“PRTS 模式”。

用户会话、配置、凭据和语料保存在 userdata 目录。请勿把整个 userdata 目录公开分享。
本程序只监听 127.0.0.1，不会默认向局域网开放。

“Stop PRTS.cmd”可停止仍在后台运行的 Host。
日志位于 userdata/logs/dsh.log；其中本地访问 token 会被隐藏。
